Multiplicación por desplazamiento. 
Se implementa una suma de 2 números binarios de 4 bits, donde la suma se realiza bit por bit, tomando en cuenta el acarreo de cada operación. 
Se imprime una tabla con las 4 iteraciones y el resultado final en binario y decimal. 

Ejemplo
M = 1001
Q = 0011
Resultado binario = 00011011
Resultado decimal = 27

Tecnologías ocupadas:
Java y Eclipse IDE Version: 2026-09 (4.41.0)
